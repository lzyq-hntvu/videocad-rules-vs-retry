## 2. 当前结论（用于7天计划修正）

1. `VideoCAD` 对应环境应写为 `Onshape`（浏览器 CAD），不是 `SolidWorks`
2. 可通过 Dataverse API 获取文件元数据、文件大小、数据文件 ID
3. 适合7天冲刺的起点文件：
- `readme.md`（最小验证）
- `qa.json`（约 5MB，可快速解析）
- `action_json.zip`（约 23MB，后续 Day2 可下载）
- `action_raw.zip`（约 23MB，后续可选）

## 4. 风险与注意事项

1. Dataverse 网页 HTML 可能依赖跳转/动态渲染，命令行直接抓取为空；优先使用 API。
2. 大体量视频分片（`0000.zip` 等）单文件通常为 10GB~20GB，不适合作为 7 天冲刺首批样本。
3. 申报书中应明确写“公开数据集 + 自建任务清单/脚本/预实验观察”，不能把公开数据规模等同于本人前期工作规模。
