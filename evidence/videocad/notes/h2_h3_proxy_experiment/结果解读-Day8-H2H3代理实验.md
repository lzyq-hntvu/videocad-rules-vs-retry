# 结果解读（Day8：H2/H3 机制代理实验）

更新时间：2026-02-26

## 1. 本轮是否得到机制信号（结论）

得到，且方向符合预期：

1. `H3`（误差传播阈值）：复杂度越高，成功率曲线越早跌破 `0.5`（阈值更低）
2. `H2`（规则抑制级联失败）：加入最小规则约束后，各复杂度层阈值整体抬升，失败位置延后

说明：当前为“事件级符号链代理实验”结论，不是 GUI 元素框级实验结论。

## 2. 阈值代理结果（`epsilon*`: success_rate < 0.5）

### 无规则（`no_rules`）

1. `low`: `ε* = 0.04`
2. `medium`: `ε* = 0.02`
3. `high`: `ε* = 0.02`

### 有规则（`with_rules`）

1. `low`: `ε* = 0.08`
2. `medium`: `ε* = 0.06`
3. `high`: `ε* = 0.04`

### 解读

1. 同一复杂度层下，规则约束使阈值明显右移（抬升）
2. 不同复杂度层下，高复杂度链条对误差更敏感（更早坠落）

这两点分别对应 `H2` 与 `H3` 的机制入口。

## 4. 失败原因结构（辅助解释）

无规则条件下常见失败原因包括：

1. `finish_mismatch`（关闭动作与栈顶不一致）
2. `stack_underflow`
3. `mismatch_rate_threshold`

有规则条件下：

1. `finish_mismatch/underflow` 显著减少（被规则投影吸收）
2. 失败更多体现为 `mismatch_rate_threshold`（即规则缓解了语法级崩溃，但无法消除全部语义偏差）

这一变化可作为 H2 的机制解释支撑：规则约束主要通过**防止非法动作传播、限制错误状态扩散**来提高鲁棒性。
