# 规则约束是否真的优于朴素重试

**实验方案 v1 · VideoCAD 符号动作链 · 2026-09-14**

把国自然本子（6267076144）里的 H2/H3 代理实验收敛成一篇可发表的单问题实证研究。四步改造，全部跑在已有管线上，不需要新建任何环境。

---

## 范围声明

这是一项在 **VideoCAD（Onshape 浏览器 CAD 录制）派生动作链**上的受控误差注入**模拟研究**。标题、摘要与 Limitations 三处都必须这样写。

**本文主张**：在符号动作链层面，规则约束相对朴素重试的增量、及其随复杂度与误差类型的变化。

**本文不主张**：对真实视觉 GUI 智能体的评测结论。图像侧感知闭环未完成、元素框级定位误差未验证、`qa.json` 三方映射未恢复——这三条写进 Future Work，不藏。

## 单一研究问题

> 在多步骤动作链上注入受控误差后，规则约束相对于朴素重试是否存在可重复的增量？该增量在哪些复杂度层与误差类型上成立，在哪些条件下消失？

## 步骤一 · 补上朴素重试基线

现有代理实验只有 `no_rules` 与最小规则集两臂。缺了重试基线，「规则抬升阈值」这个结论没有反驳面——注入误差后朴素重试同样会抬高成功率。**这一步决定整篇论文是否成立。**

### 表 A — 对照臂定义

| 标识 | 定义 | 角色 |
|---|---|---|
| `no_rules` | 无任何约束，误差按 ε 注入后直接执行 | 下界 |
| `retry_selfreport` | 仅当动作被环境自身判为非法时重试该步，每步至多 k 次 | 现实重试基线 |
| **`retry_oracle`** | 任一步偏离预期状态转移即重试（完美失败检测），每步至多 k 次 | **重试的上界——主对照** |
| `min_rules` | 栈一致性收束 + 非法关闭修正（沿用本子代理实验口径） | 待检验项 |
| `rules_retry` | `min_rules` + `retry_selfreport` 组合 | 互补还是冗余 |

> **主断言必须对 `retry_oracle` 成立。** 规则若只赢过 `retry_selfreport`，如实写成较弱的结论，别含糊过去——审稿人一定会问这一句。

### 表 B — 预算与参数

| 项 | 设定 | 敏感性 |
|---|---|---|
| 动作执行预算 B | 每条链 `B = L × (1 + r)`，五臂共用同一 B；规则检查不计入 B，但规则臂同样不得超出 | r = 0.2 主<br>r = 0.5 副 |
| 单步重试上限 k | 超出即判该步失败，继续向下走 | k = 2 主<br>k ∈ {1, 3} 副 |
| **误差抽样配对** | 同一条链、同一 ε、同一重复编号下，**五臂共用同一组误差随机数**（common random numbers） | — |

> 配对设计这一条不要省。臂间差异的方差会大幅下降，等效于在不增加任何计算量的前提下提升统计功效——是整套方案里性价比最高的一个决定。

## 步骤二 · 扩样并切出独立确认集

现在的 90 条链抽自 135 条联动样本池，且同一批数据既调管线又出结论。扩到 600 条、并与开发集不相交，是把「链选择偏差」从结论里剥掉。

### 表 C — 样本与网格

| 项 | 设定 |
|---|---|
| 底座 | 44,291 条动作链 / 三层 14,616 · 15,059 · 14,616 |
| 开发集 | 原 90 条（30/30/30）保留，仅用于调管线与冒烟测试，**结论不引用** |
| **确认集** | **600 条 = 200 / 200 / 200**，分层**等量**抽样（非按层比例——层间对比需要等量才能功效均衡），与开发集**不相交** |
| 随机种子 | 固定并在论文中写出；抽样脚本与种子一并作为补充材料 |
| 链级记录 | 链长 L、状态依赖深度、动作类型分布——供后续解释异质性 |
| ε 网格 | `0, .01, .02, .03, .04, .05, .06, .07, .08, .09, .10, .12, .15`（13 档） |
| 重复数 | `20`（由 40 下调） |

> **为什么重复数可以从 40 降到 20。** 重复数只压同一条链上的注入随机性；链数压的是链选择偏差。把 `90×40` 换成 `600×20`，总样本量翻 3 倍，而且换掉的是更要命的那一种偏差。
>
> ε 网格向上补到 0.15，是因为加了规则和重试之后 ε\* 会右移，原来的 11 档可能盖不住上界。

### 表 D — 运行次数

| 实验 | 构成 | 次数 |
|---|---|---|
| 主实验 | 5 臂 × 600 链 × 13 ε × 20 重复 | 780,000 |
| 消融（步骤三） | 9 条件 × 600 链 × 3 ε × 20 重复 | 324,000 |
| 合计 | 对比现状 2×90×11×40 = 79,200 | **1,104,000** |

> **先在开发集上测单次运行耗时。** 符号链模拟通常在毫秒级，若单次 1 ms 则全量约 18 分钟，10 ms 则约 3 小时。如果实测远高于此，回调重复数而不是砍链数——理由见上。

## 步骤三 · 拆开规则类型，报边际贡献

本子把规则分成合法集 / 顺序 / 一致性 / 坐标四类，但代理实验里它们被打包成一个「最小规则集」。不拆开，就回答不了评审 3 说的「规则为何有效、在何种区间内有效」。

九个条件：四类**单独启用**、四个**留一法**（全集去掉其中一类）、加全集。为控制运行量，消融只在三个代表性 ε 点上跑：`0.02（低） · 0.05（中） · 0.08（高）`，且只用确认集。

### 表 E — 消融输出

| 量 | 含义 |
|---|---|
| 边际贡献 | Δ成功率、Δε\*、Δ失败位置——单独启用与留一法两个方向都报 |
| 覆盖率 | 该规则在多少比例的步上被触发（本子图 4 已有这个量，这里落实） |
| 收缩比 | 触发时把候选动作集压缩了多少 |

> 覆盖率和收缩比是把「规则」从工程补丁变成可量化结构变量的关键——它们解释了为什么某类规则有效，而不只是报告它有效。如果某一类单独贡献不显著，明写。

## 步骤四 · 修正阈值口径，给 ε\* 配区间

本子正文写「成功率首次低于 0.5」，图 6 的判据虚线却画在 0.7。而且现在报的 ε\* 全部恰好落在网格点上（0.02 / 0.04 / 0.06 / 0.08）——说明取的是格点值，分辨率被步长锁死，且没有任何区间估计。

### 表 F — ε\* 估计协议

| # | 修正 |
|---|---|
| 1 | 主判据定为 **0.5**（正文口径，更保守）。图 6 的虚线改到 0.5。 |
| 2 | **0.7 作为敏感性分析**并行报告——本子 p.14 自己定的规矩：主口径不变，备选口径仅用于稳健性比较。照做。 |
| **3** | ε\* 用**线性插值**在相邻网格点之间求交点，不再取格点值。 |
| **4** | 对**链**做 bootstrap（B = 1000）得 ε\* 的 95% CI。重抽样单位是链，不是 run。 |

> **第 3、4 条合起来才是这一步的意义。** 点估计落在格点上时，0.02 与 0.04 的差异有可能完全是步长的伪影。插值加区间之后，「规则抬升阈值」才第一次成为可检验的断言，而不是一句观察。

### 表 G — 主分析

| 项 | 设定 |
|---|---|
| **主模型** | 混合效应 logistic：`success ~ arm × ε × stratum + (1 \| chain)` |
| 为什么要随机截距 | 同一条链的 20 次重复**不独立**。现有口径把重复当独立样本，会低估标准误、虚高显著性。 |
| 主检验 | 控制 ε 与复杂度后，`min_rules` vs `retry_oracle` 的固定效应 |
| 多重比较 | Holm 校正 |
| 效应量 | 报 odds ratio 与 **Δε\* 绝对值**，不只报 p |
| 传播增益 G | 沿用本子定义：首次失配后 k = 3 步内进入失败态的比例；及首次失配到恢复/终止的连续失败长度 |
| 失败位置 | 首次失配步位归一化 `step_index / L` 的分布，按臂分组，KS 检验 |

## ⚠ 决策门 · 第 2 周结束时执行

**这条规则必须现在写死，拿到结果之后不得修改。预先登记的意义全在于此。**

```
若 Δε*( min_rules − retry_oracle ) 的 95% CI 跨 0
→ 规则没有可证实的增量
→ 停止投稿
```

那不是白干。「在符号链层面，一致性规则相对完美检测重试没有可测增量」本身是一个干净的负结果，它直接告诉你下一轮选题该往哪走——而且是在花掉 6300 元注册费**之前**知道。
